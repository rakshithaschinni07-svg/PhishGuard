How URL Analysis Works

1. URL Validation

Checks whether the entered URL uses HTTP or HTTPS and has a valid network location.

2. Security Indicators

Checks for patterns such as IP addresses, suspicious symbols, long URLs and unusual ports.

3. Risk Score

Indicators contribute points to a rule-based risk score.

4. Risk Level

The score is classified as Low, Medium or High.
