How Risk Scoring Works

Each detected indicator contributes points to the URL's risk score. Indicators with stronger warning characteristics contribute more points.

The current risk categories are:

  • 0 points: No Obvious Warning
  • 1–2 points: Needs Review
  • 3 or more points: Potentially Suspicious

About PhishGuard

PhishGuard is a defensive cybersecurity project designed to analyze URLs using rule-based security indicators.

The project uses Python and Flask for the backend, HTML and CSS for the frontend, and SQLite for storing scan history.

The analysis is intended for educational and security-awareness purposes.

Important:

A high risk score does not by itself prove that a website is malicious, and a low score does not guarantee that a website is safe. Results should be treated as indicators for further review.
